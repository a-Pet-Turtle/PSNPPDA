# PSNPPDA  
Its the Portable Super-Not-Pockatable Personal Digital Assistant!!!  
It is what the name implies. It's *super not pockatable*.  

## What to do with these files
`/models/freecad/` contains the FreeCAD source files because the whole thing was designed in FreeCAD.  
`/models/print/` contains the printable `.stl` files.  
`/pictures/` contains pictures of the final print and the assembly.
